Website erstellen lassen in München: von dem, der sie auch baut

Sie reden mit der Person, die den Code schreibt. Kein Projektleiter dazwischen, kein Junior, der das Briefing zum dritten Mal missversteht.

Was Website erstellen lassen bei mir bedeutet

  • Handgeschriebener Code statt Baukasten oder gekauftes Theme: die Seite kann genau das, was sie können soll, und nichts weiter
  • Statisch, wo es geht: keine Datenbank, die bei jedem Aufruf antworten muss, kein System, das monatlich Updates verlangt
  • Zweisprachig, wenn nötig, jede Sprache auf eigener Adresse, damit Google beide findet
  • Redaktion: wenn Sie selbst Texte ändern wollen, kommt WordPress mit ACF dazu. Wenn nicht, entfällt es und mit ihm die Wartung

Was ich nicht mache: monatliche Pakete für Leistungen, die nicht stattfinden.

Agentur, Baukasten oder Website erstellen lassen bei einem Einzelnen

  • Baukasten: günstig, sofort, begrenzt. Richtig für eine Visitenkarte
  • Agentur: richtig, wenn viele Beteiligte, Kampagnen und laufende Betreuung nötig sind. Kostet Aufschlag für die Struktur
  • Einer, der es selbst baut: richtig, wenn die Seite konkret etwas leisten soll und Sie direkt mit dem reden wollen, der sie baut

Ich sage ab, wenn ein Projekt bei mir schlechter aufgehoben wäre. Das kommt vor und ist kein Drama.

Wie ein Projekt in München abläuft

  1. Gespräch: wofür ist die Seite da, wer soll darauf etwas tun
  2. Entwurf, Struktur und Aussehen, bevor eine Zeile Code entsteht
  3. Bauen, mit Zwischenständen zum Anschauen, nicht als Überraschung am Ende
  4. Live, Domain, Zertifikat, Suchkonsole, Übergabe

Persönlich in München oder per Video, je nachdem was passt.

Was das kostet

Keine Preisliste, weil eine Landing-Seite und ein Shop nichts miteinander zu tun haben. Aber auch keine Angebote ins Blaue: nach dem ersten Gespräch bekommen Sie eine Summe und einen Umfang, an die ich mich halte.

Wenn Sie im Gespräch feststellen, dass es doch ein Baukasten tut: auch gut. Das Gespräch kostet nichts.
