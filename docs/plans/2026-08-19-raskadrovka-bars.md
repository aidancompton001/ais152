---

## Правила, действующие на всю раскадровку

**Прокрутка = время.** Ни один ролик не играет сам. Процент прокрутки секции = номер кадра. Крутишь вниз — вперёд, вверх — назад.

**Назад = обратное воспроизведение.** Отдельных роликов возврата нет.

**Поза покоя — узел.** Каждый ролик начинается кадром «стоит спокойно» и заканчивается устойчивым состоянием: держит жест или идёт по циклу.

**Текст и барс на одном слое.** Заголовок перекрывает ноги, барс за буквами. Не колонки рядом.

**Направление — зеркалом.** Один цикл шага, влево — отражение по горизонтали. Шестерёнка на футболке по центру, отражение незаметно.

## СЦЕНА 3 · Проекты

**Фон:** `#141311` тёплый уголь, **не чёрный**.
**Прокрутка:** 58–90 %

Барс **бежит по земле, без тренажёра**. Мимо него **проносятся шестнадцать работ** — как декорации в платформере. Он движется, они движутся навстречу.

| Секунда | Барс | Контент |
|---|---|---|
| 0,0 | цикл бега, лапы по земле, хвост балансирует | пусто |
| 0,2 | бежит | проносится 1 → `Henner Heede` |
| 0,4 | бежит | 2 → `Taxi Mönnigmann` |
| 0,6 | бежит | 3 → `Sorry Sara` |
| … | цикл, темп = скорость прокрутки | … по одной работе каждые 0,2 с |
| 3,2 | бежит | 16 → `YY-DGUV Prüfservice` |
| 3,6 | **переходит на шаг, оборачивается** на карточку, оставшуюся в кадре | карточка укрупняется, появляется подпись |

**Скорость бега привязана к скорости прокрутки.** Крутишь быстро — бежит быстро. Остановился — переходит на шаг и оборачивается.

**Ролик №4:** цикл бега, 5 с, зацикленный. Начало и конец совпадают по фазе шага.
**Ролик №5:** `бег → шаг → остановка → оборачивается` 3 с.

**Карточки ведут на** `/projekte/*.html`.

## Чего раскадровка НЕ ломает

**34 проиндексированных адреса, тексты и разметка остаются как есть.** Барс живёт на главной. Карточки услуг и проектов — настоящие ссылки на настоящие страницы, а не декорации.

**Страницы услуг для ремесленников и практик остаются строгими**, без персонажа: они уже в выдаче, и там он мешает продавать.

**Вес.** Ролики разбираются на кадры, кадры жмутся в WebP. Шесть сцен по 30 кадров — меньше, чем один скриншот проекта в полном размере.
