# Правила текстов страниц проектов (`/projekte/*.html`)

Внесено 11.09.2026 приказом CEO. Задача AIS152-IDX-001: 16 страниц проектов по 72–138 слов
лежат в «Crawled – currently not indexed» кандидатами — их дописывают, а не закрывают noindex.

## Источник

- Текст пишется **только** из папки проекта `c:\Projects\<проект>\` (CLAUDE.md, DEVLOG.md, docs/)
  и из `data/projects.json`. Для каждого утверждения — файл-источник в реестре HRC задачи.
- Нет источника — нет утверждения. Проект без данных (POMP) ждёт текста от CEO.
- Цифры результата (заявки, трафик, продажи, скорость) — только если записаны в файлах проекта.
  Иначе результат описывается словами, без чисел.

## Запрещено публиковать

- IP-адреса, хосты серверов, доступы, внутренние адреса админок
- Суммы: цена проекта, ставки, счета, бюджеты клиента
- Сроки и условия оплаты
- Переписку с клиентом: цитаты из WhatsApp, писем, чатов — ни дословно, ни пересказом
- Имя клиента, название его фирмы, ссылку на живой сайт и узнаваемый скриншот — **только с согласия**,
  записанного в `data/consents.json`. Без согласия страница обезличивается:
  «Imkerei aus Hessen», «Taxiunternehmen in Norddeutschland» и т. п.

## Объём и форма

- 300+ слов уникального немецкого текста на страницу: Ausgangslage / Aufgabe → Umsetzung → Ergebnis → Technik
- Без точек в заголовках и кнопках (правило MainCore)
- Перед публикацией — ревью #14: каждое утверждение сверено с источником, запреты выше проверены пробой
