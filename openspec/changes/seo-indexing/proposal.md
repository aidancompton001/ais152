# Индексация ais152.com в Google

## Зачем

CEO: сайт должен индексироваться как надо, работать в Google Search Console
и в Google Business. Задача разбита на две части: то, что делается в коде
(эта работа), и то, что делает только владелец аккаунта — вход в Search
Console и создание карточки Google Business (передаётся CEO отдельно).

## Что измерено до правок

Дата замера: 2026-08-17, живой сайт https://ais152.com

| Проверка | Результат |
|---|---|
| Главная, robots.txt, sitemap.xml, юр. страницы | HTTP 200 |
| www.ais152.com | 200, отдаёт тот же адрес без www |
| Файл подтверждения Search Console `google9d7cbb1b47be4897.html` | 200 |
| `noindex` на главной | нет |
| h1 в исходном HTML (не дорисован скриптом) | есть |
| JSON-LD Person + ProfessionalService + WebSite | есть |
| Несуществующий адрес | 404 |

Индексация в самом Google **не проверена**: доступного мне поиска Google нет,
а Search Console требует входа CEO. Заявлять «сайт в индексе / не в индексе»
на основании стороннего поисковика запрещено (Закон 27 §1).

## Найденные дефекты

**Д-1. Восемь страниц-сирот открыты для индексации.**
`concept-a … concept-g.html` — дизайн-черновики («Concept A — Apple Bento»,
«Concept G — Dark Aurora»), `quiz.html` — русскоязычный квиз про соцсети.
С главной на них ноль ссылок, темы к студии отношения не имеют, языка сайта
(EN/DE) часть из них не держит. Для Google это тонкие страницы без входящих
ссылок: они тратят бюджет обхода и размывают тему домена.

**Д-2. Карта сайта содержит 2 адреса из 7 живых.**
Отсутствуют impressum, datenschutz, agb, widerruf, avv. Дата правки главной
в карте — 2026-04-28, тогда как файл менялся 2026-08-14: Google получает
сигнал «страница не менялась четыре месяца».

**Д-3. В разметке организации нет улицы и индекса.**
Есть только «Munich, Bayern, DE». Google связывает сайт с карточкой Business
по совпадению названия, адреса и телефона; без улицы связка не образуется.
Адрес уже опубликован в Impressum по закону, новых данных не раскрывается.

## Что делается

1. `noindex, nofollow` на восемь страниц из Д-1
2. Карта сайта переписывается: все живые публичные адреса, даты правок берутся
   из журнала git, а не пишутся от руки
3. В `ProfessionalService` добавляются `streetAddress` и `postalCode`,
   слово в слово из Impressum

## Что НЕ делается в этой работе

- Вход в Search Console и отправка карты сайта — только CEO
- Создание карточки Google Business — только CEO, требует подтверждения
  адреса по почте
- Смена содержания страниц, тексты, ключевые слова

## Критерии приёмки

- [ ] Восемь черновых страниц отдают `noindex` на живом сайте
- [ ] Карта сайта содержит 7 адресов, каждый отвечает 200, ни один не `noindex`
- [ ] Даты в карте совпадают с журналом git
- [ ] Разметка организации содержит улицу и индекс, совпадающие с Impressum
- [ ] Главная страница `noindex` НЕ получила
